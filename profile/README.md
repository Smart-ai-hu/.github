# Smart-AI

**Weboldalak, webshopok és üzleti rendszerek fejlesztése — AI-alapú automatizációkkal.**

## Szolgáltatásaink

- 🌐 **Weboldal fejlesztés és üzemeltetés** — modern, gyors, konverzióra tervezett oldalak, folyamatos üzemeltetéssel és monitoringgal
- 🛒 **Webshop fejlesztés és üzemeltetés**
- 📱 **Mobilalkalmazás fejlesztés**
- 🏢 **Céges rendszerek és ERP modulok** — kisebb belső eszközöktől a teljes vállalatirányítási megoldásokig
- 🤖 **AI automatizációk** — ismétlődő üzleti folyamatok automatizálása

## Hogyan dolgozunk

Minden projekt verziókezelt, automatizált CI/CD folyamattal készül: minden változás
tesztelésen megy át, mielőtt élesbe kerül, az éles oldalakat pedig folyamatos
monitoring figyeli.
